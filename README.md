A modern, high-conversion web application built for Phenex Fishing Line. This project serves as a premium brand showcase and product catalog, featuring fluid scroll animations, secure authentication, and a scalable component-based architecture. 

## 🚀 Key Features

* **Premium UI/UX:** Implemented a luxury "glassmorphism" design system using Tailwind CSS, complemented by complex scroll-linked 3D animations via Framer Motion.
* **Authentication & Authorization:** Secure user session management and protected routing utilizing the Backendless BaaS ecosystem.
* **Type-Safe Architecture:** End-to-end TypeScript implementation ensuring robust component props, state management, and API integrations.
* **Scalable Routing:** Public and private route separation using React Router v6 layout patterns.
* **Performance Optimized:** Lazy loading, optimized asset delivery, and efficient React rendering lifecycles.

## 💻 Tech Stack

* **Core:** React 18, TypeScript, Vite
* **Routing:** React Router v6
* **Styling:** Tailwind CSS, clsx + tailwind-merge
* **Animations:** Framer Motion
* **Backend/BaaS:** Backendless (Auth & Database)
* **Icons:** Lucide React

## 📂 Project Architecture

The application is structured for scalability and maintainability:
src/
├── components/   # Reusable, presentation-focused UI components (Hero, Cards, Navigation)
├── configs/      # Third-party integrations and environmental setups
├── context/      # Global state management (AuthContext)
├── layouts/      # Route wrappers for Public and Protected access control
├── lib/          # Utility functions (e.g., Tailwind class merging)
├── pages/        # Top-level route components
└── App.tsx       # Root component and router configuration
